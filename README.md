📊 Revenue Cycle Management (RCM) Funnel Analytics – US Healthcare
🔍 Project Overview

This project presents an end-to-end Revenue Cycle Management (RCM) analytics dashboard built using Power BI, designed to analyze claim flow, financial performance, denial patterns, and accounts receivable (AR) behavior in the US healthcare system.

The dashboard is structured across three analytical layers:

Executive Overview – high-level revenue and performance KPIs

RCM Funnel Analysis – claim lifecycle tracking from submission to closure

Denials & Rework Analysis – root cause and financial impact of denials

🗂 Dataset & Data Disclaimer

Important Note on Data Usage

This project uses a synthetic but industry-aligned US healthcare claims dataset.

The dataset is designed to replicate real-world Revenue Cycle Management (RCM) workflows, including claim submission, adjudication, denial behavior, accounts receivable (AR) aging, and payer reimbursement patterns.

While the data does not represent real patient information, the structure, distributions, financial relationships, and operational logic are modeled on standard US healthcare billing and insurance practices.

This approach ensures the analysis remains HIPAA-safe, ethical, and suitable for portfolio demonstration while accurately reflecting real-world RCM scenarios.
